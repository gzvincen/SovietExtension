# ⚠️ 警告 / WARNING

## 🔴 仅限 Intel (x86_64) 测试
本分支**只在 Intel Mac 上测试过**，Apple Silicon (M1/M2/M3/M4) **未测试**。

## 🔴 微信版本限制
**仅支持微信 4.1.10.53 (build 268853)**，其他版本不保证可用。

## 🔴 分支说明
**必须使用 `feat/intel-x86_64-support` 分支**，不要使用 `master` 分支。

## 🔴 不可用功能
以下功能在本分支中**不可用**（点击会提示"暂时不支持此功能"）：
- ❌ 退群监控
- ❌ 使用系统浏览器

## 🔴 风险声明
**所有功能仅在我的个人电脑上测试过**，不保证在其他设备上稳定。  
**谨慎安装**，使用风险自担。建议先在备用账号/环境测试。
